# Athens Tours – Frontend

React 19 + TypeScript + Vite + Tailwind v4 + shadcn/ui.

## Run

1. Backend must be running on http://localhost:8080 (and allow CORS from http://localhost:5173).
2. `copy .env.example .env`  (Windows)  – contains `VITE_API_URL=http://localhost:8080/api/v1`
3. `npm install`
4. `npm run dev`  -> http://localhost:5173

Seeded admin (local dev): `admin` / `Passw0rd!`
